# Syntra Build — Architecture Decision Records

## Accepted Decisions

| ADR | Decision |
|---|---|
| ADR-001 | Syntra owns authoritative workflow state |
| ADR-002 | Telegram is the initial human interface |
| ADR-003 | GitHub is the canonical source-control platform |
| ADR-004 | Generated repositories are public by default |
| ADR-005 | Codex receives no privileged GitHub credentials |
| ADR-006 | Syntra controls commits, pushes, PRs, and merges |
| ADR-007 | SQLite is the initial persistent state store |
| ADR-008 | Syntra Build uses Python 3.14 |
| ADR-009 | Use a single service before microservices |
| ADR-010 | GitHub Actions handles heavy and cross-platform CI |

These ADRs record architectural decisions established by the Syntra Build design documents.

If a decision changes later, the preferred approach is to create a new ADR that supersedes the earlier decision rather than rewriting architectural history.
